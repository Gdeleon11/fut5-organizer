# F5 Manager — logo proposals (Monogram selected)

Three vector directions for review. **Selected: F5 Monogram (2026-11-22)** — applied to the app mark, favicon, PWA icons and share image (`frontend/public/brand/f5-monogram.svg`). Pulse and Club stay here as reference only.

| Concept | Folder | Idea |
|---|---|---|
| 1. F5 Monogram | `monogram/` | Rounded badge, F and 5 built from blocks. Reads at 16 px. |
| 2. F5 Pulse | `pulse/` | Centre-circle ring + pulse line (match energy, and F5 = "refresh"). |
| 3. F5 Club | `club/` | Club crest with the monogram and a star. League/tournament tone. |

Each folder: `logo-light.svg`, `logo-dark.svg`, `favicon.svg`, `mobile-nav-light.svg`, `mobile-nav-dark.svg`.
Open `index.html` for the side-by-side review sheet.

Notes for the chosen one: the marks are pure paths; the wordmark uses Oswald 700 (the app's display font) as `<text>` —
convert it to outlines before shipping as a standalone asset. Colours follow the Neon palette (#5be584 / #0a6633 on light).
